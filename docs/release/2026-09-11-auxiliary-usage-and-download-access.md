# Auxiliary usage and file-download access

Non-streaming delegate generations previously recorded their usage only after the AI SDK completed the model step, including its tools. Parent cancellation while a read was pending could therefore lose a completed provider receipt. The shared observer now handles doGenerate as well as doStream, normalizes both through the same path and reports the receipt before SDK tool execution or structured-output validation. Delegate completion keeps its fallback path but does not record an already observed generation twice.

A real AI SDK generateText regression reaches a pending read and checks that the provider cost is already recorded, then cancels the parent. The original source failed this check with zero cost callbacks. Passing cases also cover two model steps, invalid final JSON, and refusing a requested child read after the provider receipt has crossed the existing delegate cost ceiling. This is not a promise that a provider call cannot itself overshoot that ceiling; its spend is known after its response. Four observer/delegate/main-usage suites passed 29 tests. No paid model call was needed.

Token totals now include accepted summary input/output and derive missing per-step totals from input plus output. Eight regression/preservation cases cover mixed missing totals, repeated summaries and the existing reset policy. Five overlapping tracker/runner suites passed 91 tests. Cost-source, mixed priced-subtotal and fallback-waiver policies were deliberately not changed by the arithmetic fix. Failed/blank summary receipts, title costs and retained waived-provider expenditure remain separate work.

AllFilesDialog previously exposed individual download buttons only on mouse hover: touch users could not see them, and a keyboard-focused button remained transparent. Coarse-pointer controls are now visible and 44 by 44 CSS pixels; fine-pointer rows retain their compact 24-pixel controls and reveal them on keyboard focus as well as hover. Each control has a file-specific accessible name. The offline browser fixture renders the actual component with the application's global CSS, isolates network/backend calls, and checks keyboard/touch activation, geometry and multi-file navigation. It does not simulate a real remote file download or replace full-device acceptance testing.
