# Studio stock capability reference archive

The licensed stock masters documented below are retained as a fallback archive. The active Studio stage now uses the original art-directed `cinematic-v2` set; its small UI derivatives remain in this directory and include `cinematic-v2` in their filenames. **No reference media is presented as output from the listed model or provider.**

The active Studio stage uses the credited 4K masters below. The interface also carries local display derivatives from those same masters: 144x108 WebP thumbnails for the 48px model rail and 800x480 WebP images for the production-direction cards. These smaller files keep the original attribution and license; exact source mappings, byte sizes and SHA-256 hashes are recorded in `manifest.json`.
