# Studio showcase v3

This set gives every Studio model its own local presentation reference. The
references demonstrate production directions only; they are not represented
as output from the named model or provider.

- The seven image references are original RIFT Studio compositions mastered
  locally to 3840 x 2160 WebP.
- The five video references use five separate original keyframes created for
  this set, mastered to 3840 x 2160, then rendered as restrained eight-second
  H.264 camera studies at 30 fps.
- Every model has a dedicated 384 x 216 rail thumbnail so the library never
  repeats another model's poster.
- Video files contain no audio, typography, logos, or third-party footage.
- Desktop surfaces retain the 3840 x 2160 masters while `-mobile` WebP and MP4
  derivatives preserve the same framing at 1280 x 720 for efficient phones.

Original image-generation sources were retained in the local Codex generated
image store. Responsive WebP masters, thumbnails, and MP4 presentation reels
are checked into this directory for deterministic product rendering.
