# Studio cinematic reference set v2

This directory contains original, art-directed capability references for the
Studio model browser. They are presentation references only and are not shown
as output from any listed model or provider.

## Original stills

The five source compositions were generated with the built-in image generation
workflow on 2026-07-19, then converted locally to high-quality WebP:

- `product-story.webp`: sculptural graphite headphones in a dark architectural studio
- `character-night.webp`: rain-lit editorial character portrait in a brutalist passage
- `architecture-blue-hour.webp`: coastal basalt pavilion at blue hour
- `material-chrome.webp`: liquid chrome, smoked glass and translucent fabric study
- `fashion-motion.webp`: silver editorial garment captured in controlled motion

`fast-ideation.webp` and `object-edit.webp` are responsive 16:9 crops from the
earlier original cinematic set.

## Motion references

The five MP4 reels are local 1920x1080, 30 fps, 7.8-second H.264 sequences made
from the original stills with restrained camera movement and crossfades. They
contain no audio, text, logos or third-party footage.

Small model-rail thumbnails and production-direction card derivatives live in
`/public/studio/references` and use `cinematic-v2` in their filenames.
