# Provider marks

OpenAI, Gemini, Grok/xAI, Kimi, Qwen and Z.ai were copied from the existing RIFT public/brands/providers assets. Claude Color and Hunyuan Color were rendered from the installed @lobehub/icons package's React components (MIT); see node_modules/@lobehub/icons/LICENSE. Preserve original colors for multicolor marks. The monochrome OpenAI, xAI and Z.ai marks adapt to the native foreground for light/dark contrast. Do not apply the interface accent color to provider marks.

Grok uses the Grok Mono mark from the installed @lobehub/icons package (MIT), replacing the xAI wordmark. Studio previews reuse local showcase-v3 directional artwork; they are visual references, not promises of generated output.
